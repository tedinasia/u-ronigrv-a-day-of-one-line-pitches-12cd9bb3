One sentence, at most 240 characters, that would convince a friend who has
never coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## The pitch

> You've already told me that app idea three times — say it once to an AI
> agent on make.fun and it builds a first version you can try, no code
> from you, and the worst that happens is you find out sooner whether it
> works.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (UTF-8, one sentence,
218 characters). The program uses only the Python standard library.
